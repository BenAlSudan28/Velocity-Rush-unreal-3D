# نماذج السيارات

استورد ملفات GLB الثلاثة إلى `/Game/Vehicles/` في Unreal Content Browser **مع الاسم الأساسي نفسه**. الكود يبحث عن هذه المسارات:

- `/Game/Vehicles/AerionGT.AerionGT`
- `/Game/Vehicles/VortexSVX.VortexSVX`
- `/Game/Vehicles/TerraRallyS.TerraRallyS`

إذا لم تُستورد النماذج، يستمر المشروع بهياكل إجرائية احتياطية. ملفات GLB مصدرية خارج `Content` وليست Unreal `.uasset`؛ لم يُختبر استيرادها أو تحجيمها في محرر UE داخل هذه البيئة. التصاميم أصلية وخيالية ولا تستخدم شعارات أو أصول سيارات شركات بعينها.
