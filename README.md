# Velocity Rush 3D — Unreal Engine

مشروع سباق سيارات ثلاثي الأبعاد مستقل عن Godot، بمصدر C++ لـ **Unreal Engine 5.5.x**. لا توجد في هذه الحزمة ملفات Godot. أرشيف Godot الذي رفعه المستخدم بقي نسخة احتياطية منفصلة ولم يُحذف من مساحة العمل؛ ناتج هذا التسليم هو مشروع Unreal جديد.

## ما يتضمنه المشروع

- قائمة عربية فعلية عند بدء التشغيل، مرآب لاختيار سيارة، سباق سرعة محدد بزمن، قيادة حرة، وقوائم إيقاف/استئناف ونتائج وإعادة.
- حلبة حضرية مغلقة ذات منعطفات، حواجز، مبانٍ إجرائية، أرضية مدينة وإضاءة وقت التشغيل.
- لاعب وأربعة منافسين آليين في سباق السرعة؛ القيادة الحرة تعرض اللاعب وحده.
- ثلاث هويات سيارات خيالية مميزة لونيًا وأدائيًا، مع هيكل منخفض الأوجه يتولد داخل Unreal. ملفات GLB اختيارية مرفقة كمصادر؛ بعد استيرادها إلى `/Game/Vehicles/` تستخدمها اللعبة بالاسم، وإلا تعمل المجسمات الإجرائية البديلة.
- قيادة أركيد، توجيه وفرملة وتسارع، تصادمات وعقوبة نقاط، مؤشرات سرعة ومسافة ووقت، استهلاك الوقود والنيترو، والتقاطات طريق تعيد الوقود/النيترو وتمنح نقاطًا.
- أزرار لمس للتوجيه والتسارع والفرملة والنيترو، مع لوحة مفاتيح للاختبار المكتبي.
- إعداد Android أفقي يستهدف API 28 فأعلى وC++ build workflow إلى APK على Runner ذاتي الاستضافة.

**الأسماء والتصاميم خيالية؛ ليست موديلات أو شعارات مرخصة من Ferrari أو Lamborghini أو Toyota، ولا يُدّعى ارتباط بها.** هذه قاعدة لعبة/نموذج متقدم قابل للتوسع وليست لعبة AAA مكتملة أو ضمانًا تجاريًا. الأصول الفوتوغرافية/المرخصة تحتاج توفيرًا مستقلًا. ملفات الصوت والخط الخام لا تُدمج كـ Unreal assets ولا تُشغّل بعد؛ التفاصيل في `Resources/README.md`.

## فتح اللعبة والتحكم

1. افتح `VelocityRush.uproject` في Unreal Engine **5.5.x**، واسمح بإنشاء ملفات البناء الثنائية.
2. اضغط **Play**: تبدأ القائمة، اختر **سباق السرعة** لرؤية أربعة خصوم أو **قيادة حرة**.
3. التحكم المكتبي: `W` تسارع، `A/D` أو الأسهم توجيه، `S` أو `Space` فرامل، `Left Shift` نيترو، `Esc` إيقاف مؤقت. داخل HUD توجد أزرار اللمس؛ يجب اختبار تعدد اللمس على هاتف حقيقي.

## APK وGitHub Actions

يتطلب Android build نسخة Unreal مرخصة مثبّتة على Windows، إضافة إلى Visual Studio ومتطلبات Android SDK/NDK/JDK التي يوصي بها تثبيت UE 5.5.x. لا يستطيع Runner عام في GitHub تنزيل Unreal بدلًا منك.

- محليًا: عيّن `UE_ROOT` ثم شغّل `Tools/BuildAndroid.ps1` من PowerShell.
- عبر GitHub: استخدم Runner ذاتي الاستضافة بعلامة `unreal-android`، أضف متغير Actions للمستودع `UE_ROOT` بمسار المحرك، ثم شغّل `.github/workflows/build-unreal-android.yml`. يفشل Workflow إذا غاب المحرك/SDK أو لم يتولد APK، ويرفع APK وسجلات UAT عند النجاح.
- التوقيع الناتج تجريبي؛ لا تستخدم مفاتيح Google Play أو أسرارًا في المستودع.

## الاستيراد والتحقق

استورد ملفات GLB بالأسماء الموضحة في `Resources/README.md` إلى `/Game/Vehicles/`. كما يمكن استيراد ملفات WAV إلى `/Game/Audio/` وخط Noto إلى `/Game/Fonts/`؛ الصوت والخط ليسا موصولين تلقائيًا في نسخة C++ الحالية.

تم تشغيل `python3 Tools/validate_project.py` ونجح الفحص الساكن. **لم يتوفر Unreal/UnrealBuildTool في بيئة الإنشاء؛ لذلك لم يُجمّع C++، ولم يُفتح المحرر، ولم يُنتج APK، ولم تُقَس الرسوم أو الأداء على Android.** راجع `Docs/AUDIT_AND_MIGRATION.md` و`Docs/BUILD.md` قبل البناء.
